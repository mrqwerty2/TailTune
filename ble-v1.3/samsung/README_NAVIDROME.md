# TailTune Samsung — Navidrome v1.3

Open this folder (`TailTuneSamsung`) in Android Studio. Build with **Android SDK 35, JDK 17, Gradle 8.11.1**. See the full kit's `NAVIDROME_SETUP.md` for step-by-step setup and installation.

The app is now Navidrome-only and supports original server playlists, offline download management and speed, battery readout, and a dark control-center interface. It no longer limits offline storage to a fixed 2 GB. You can remove individual cached songs, clear the cache, download a selected playlist, or download a particular song. Deleting offline music never deletes the song from Navidrome.

Upgrade the existing APK without uninstalling to preserve your cache and encrypted settings, if the signing key matches the installed app.
